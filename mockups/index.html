What is real and what is not

Real: every component ID, score, account count, transaction count, exposure figure and signal value is read from out/components.csv on the frozen test split. The graph in each mockup draws the actual nine accounts of ring02 against their shared device d_ring02. Signal names, weights, contributions and detail strings come from score_component() as it exists today, including ip_sharing sitting at weight zero per RISK-001.

Not real: nothing is wired. These are static files. Selection, hover and button states are styled but inert, and the audit-trail line is a label rather than a behaviour.

Not yet drawn: Threshold & Cost Analysis and Evaluation / Benchmark are named in the navigation but not built. The PRD scopes them as functional reference views rather than polished screens, so they are worth designing once a direction is chosen.
